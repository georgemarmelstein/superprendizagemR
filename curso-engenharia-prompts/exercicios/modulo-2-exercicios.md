# Exercícios Práticos - Módulo 2: Técnicas Avançadas

## Exercício 1: Chain-of-Thought

**Crie um prompt CoT para resolver:**

```
Problema: Uma loja oferece 25% de desconto em compras acima de R$ 200.
João comprou 3 itens: R$ 89, R$ 65 e R$ 78. Ele tem direito ao desconto?
Quanto pagará no total?
```

**Seu prompt deve guiar o raciocínio passo a passo.**

---

## Exercício 2: Few-Shot Learning

**Crie um prompt few-shot (3-5 exemplos) para classificar feedback de clientes em:**
- Bug (problema técnico)
- Feature Request (pedido de funcionalidade)
- Dúvida (pergunta sobre uso)
- Elogio (feedback positivo)

---

## Exercício 3: Zero-Shot vs Few-Shot

**Para cada tarefa, decida se é melhor zero-shot ou few-shot e justifique:**

a) Traduzir frases do português para inglês
b) Extrair informações de currículos para formato específico JSON
c) Resumir artigos científicos
d) Classificar produtos em categorias customizadas da sua empresa

---

## Exercício 4: Prompt Chaining

**Desenhe uma chain de 4-6 prompts para:**

"Analisar feedback de clientes de um produto e gerar relatório com recomendações"

**Inclua:**
- Objetivo de cada etapa
- Input e output esperado
- Formato de transição entre etapas

## Exercício 5: Role Prompting

## Exercício 6: Gestão de Contexto

**Você tem um documento de 100 páginas para analisar.**

**Descreva a estratégia que usaria:**
- Como dividiria o documento?
- Que informações priorizaria?
- Como agregaria os resultados?
- Que técnicas de otimização aplicaria?
