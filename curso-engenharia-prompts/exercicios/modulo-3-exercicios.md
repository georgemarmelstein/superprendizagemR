## Exercício 2: Análise de Código

**Crie um prompt para revisar este código:**

```python
def process_data(data):
    result = []
    for i in range(len(data)):
        if data[i] > 0:
            result.append(data[i] * 2)
    return result
```

**O prompt deve avaliar:**
- Qualidade do código
- Performance
- Legibilidade
- Sugerir melhorias
