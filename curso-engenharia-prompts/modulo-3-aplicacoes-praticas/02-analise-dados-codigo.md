# Módulo 3: Aplicações Práticas

## 3.2 Análise de Dados e Código

### Análise de Código

#### Code Review
```
Revise este código [linguagem] considerando:

✓ Checklist:
- Legibilidade e clareza
- Performance e eficiência
- Segurança e vulnerabilidades
- Boas práticas da linguagem
- Testes e tratamento de erros
- Documentação

Formato:
- Nota geral (1-10)
- Pontos fortes (2-3)
- Problemas críticos
- Melhorias sugeridas (prioridade: alta/média/baixa)
- Código refatorado (se aplicável)

[código]
```

#### Debugging
```
Este código está gerando [erro/comportamento inesperado].

Analise passo a passo:
1. O que o código deveria fazer?
2. O que está acontecendo?
3. Onde está o problema?
4. Por que o problema ocorre?
5. Como corrigir?
6. Como prevenir no futuro?

[código + erro]
```

#### Geração de Código
```
Crie uma função [linguagem] que:

Requisitos funcionais:
- [O que deve fazer]
- [Entradas esperadas]
- [Saídas esperadas]

Requisitos técnicos:
- Type hints/tipos
- Tratamento de erros
- Docstring/comentários
- Testes unitários (exemplo)
- Complexidade: O([especificar])

Boas práticas: [PEP 8/style guide específico]
```

### Análise de Dados

#### Exploração Inicial
```
Analise este dataset:

[dados ou descrição]

Forneça:
1. Visão geral (tipos de dados, tamanho, estrutura)
2. Estatísticas descritivas
3. Valores ausentes/anomalias
4. Correlações aparentes
5. Insights iniciais
6. Sugestões de análises aprofundadas
```

#### Visualização
```
Sugira visualizações para estes dados:

[dados/descrição]

Para cada visualização:
- Tipo de gráfico
- Variáveis nos eixos
- Insight que revela
- Código [matplotlib/plotly/etc]
```

#### Interpretação Estatística
```
Interprete estes resultados estatísticos para não-estatísticos:

[resultados de teste/modelo]

Explique:
- O que significa em linguagem simples
- Qual a confiança neste resultado
- Implicações práticas
- Limitações/ressalvas
```
