# Módulo 3: Aplicações Práticas

## 3.1 Escrita e Criação de Conteúdo

### Tipos de Conteúdo

#### 1. Artigos de Blog
```
Crie um artigo de blog sobre [tópico] para [público].

Estrutura:
- Título chamativo (max 60 chars)
- Introdução com gancho
- 3-5 seções principais
- Conclusão com CTA
- 800-1200 palavras

Tom: [especificar]
Incluir: exemplos práticos, dados, cases
```

#### 2. Copy Publicitário
```
Escreva copy para [produto/serviço] focando em [benefício].

Formato: [anúncio Google/post social/email]
Público: [demografia]
Objetivo: [conversão/awareness/engagement]
Limite: [caracteres]

Use framework AIDA: Atenção, Interesse, Desejo, Ação
```

#### 3. Conteúdo Técnico
```
Crie documentação técnica para [API/feature/produto].

Inclua:
- Visão geral (o que faz?)
- Pré-requisitos
- Passo a passo com exemplos
- Parâmetros e configurações
- Troubleshooting comum
- Referências

Público: [devs/usuários técnicos]
```

#### 4. Roteiros e Scripts
```
Desenvolva roteiro de vídeo sobre [tema].

Duração: [X] minutos
Estrutura:
- Hook (primeiros 5s)
- Problema/dor
- Solução
- Prova/evidência
- CTA

Tom: [conversacional/educativo/inspirador]
```

### Templates Práticos

**Email Marketing:**
```
Crie email para [campanha].

Assunto: [objetivo do assunto]
Preview text: [complementa assunto]
Corpo:
- Saudação personalizada
- Problema/oportunidade (2 frases)
- Solução/oferta (parágrafo)
- Benefícios (3 bullet points)
- CTA claro
- P.S. com urgência/bônus

Max 150 palavras
```

**Post de Redes Sociais:**
```
Crie post para [LinkedIn/Instagram/Twitter] sobre [tema].

Formato: [carrossel/vídeo/texto]
Gancho: [primeira linha impactante]
Conteúdo: [valor/educação/entretenimento]
CTA: [comentar/compartilhar/clicar]
Hashtags: [3-5 relevantes]
```
