# Módulo 3: Aplicações Práticas

## 3.4 Resolução de Problemas Complexos

### Framework de Resolução

```
Problema: [descrição]

Analise usando esta estrutura:

1. DEFINIÇÃO
   - Problema claramente articulado
   - Stakeholders afetados
   - Impacto e urgência

2. ANÁLISE DE CAUSA RAIZ
   - Sintomas vs. causas
   - 5 Porquês
   - Diagrama de Ishikawa (categorias)

3. GERAÇÃO DE SOLUÇÕES
   - Brainstorm (mínimo 5 opções)
   - Soluções de curto prazo
   - Soluções de longo prazo

4. AVALIAÇÃO
   Para cada solução:
   - Prós e contras
   - Custo e esforço
   - Riscos
   - Impacto esperado

5. RECOMENDAÇÃO
   - Solução escolhida
   - Justificativa
   - Plano de implementação
   - Métricas de sucesso
```

### Tomada de Decisão

```
Decisão: [descrição]

Framework de decisão:

1. Contexto e restrições
2. Critérios de decisão (ponderados)
3. Opções disponíveis
4. Matriz de avaliação
5. Análise de cenários (melhor/pior/provável)
6. Recomendação com confiança
7. Plano B
```
