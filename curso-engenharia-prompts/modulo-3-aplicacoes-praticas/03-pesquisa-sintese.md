# Módulo 3: Aplicações Práticas

## 3.3 Pesquisa e Síntese de Informações

### Síntese de Documentos

```
Resuma este [documento/artigo/relatório]:

[conteúdo]

Formato:
- Resumo executivo (3-4 frases)
- Pontos principais (5-7 bullet points)
- Conclusões e recomendações
- Dados/números-chave

Público: [especificar]
Foco: [aspectos de interesse]
```

### Comparação de Fontes

```
Compare as perspectivas destes [N] artigos sobre [tópico]:

[Artigo 1]
[Artigo 2]
[Artigo 3]

Análise:
- Pontos de consenso
- Áreas de discordância
- Evidências apresentadas
- Credibilidade das fontes
- Síntese balanceada
```

### Literature Review

```
Crie uma revisão de literatura sobre [tópico].

Fontes: [listar]

Estrutura:
1. Introdução ao campo
2. Principais teorias/abordagens
3. Evolução histórica
4. Estado atual do conhecimento
5. Gaps e oportunidades de pesquisa
6. Conclusões

Estilo: acadêmico
```
