# 📚 Pasta de Estilo

## Propósito

Esta pasta contém **documentos de referência** que exemplificam seu estilo de escrita pessoal.

## O Que Adicionar Aqui

Documentos que **você escreveu anteriormente** e que representam bem:

- ✍️ Seu estilo de escrita
- 📖 Sua abordagem pedagógica
- 💡 Exemplos típicos que você usa
- 🎯 Metáforas e analogias que você prefere

## Tipos de Documentos Recomendados

### ✅ Ideais

- Artigos técnicos seus
- Posts de blog sobre R ou programação
- Tutoriais que você criou
- Documentação que você escreveu
- Materiais didáticos seus

### ⚠️ Aceitáveis

- Notas de aula suas
- Apresentações detalhadas
- Documentos com > 500 palavras

### ❌ Não Recomendados

- Documentos de outras pessoas
- Conteúdo muito curto (< 500 palavras)
- Estilos muito diferentes do que você quer

## Como Funciona

O Claude Code irá:

1. **Ler todos os documentos** desta pasta
2. **Analisar padrões** de:
   - Tom e voz
   - Estrutura de frases
   - Abordagem pedagógica
   - Uso de exemplos e metáforas
3. **Criar um perfil de estilo** consolidado
4. **Mimetizar seu estilo** ao gerar capítulos

## Context Refresh

⚠️ **Importante**: Em cada geração de capítulo, os documentos desta pasta são **analisados novamente** (context refresh) para garantir consistência de estilo.

## Exemplo de Uso

```bash
# Adicionar documentos de referência
cp ~/meus-artigos/artigo-r-1.md estilo/
cp ~/blog/posts/tutorial-tidyverse.md estilo/
cp ~/papers/introducao-r.pdf estilo/
```

## Organização

Você pode:
- Adicionar quantos documentos quiser
- Organizá-los em subpastas se preferir
- Usar diferentes formatos (md, txt, pdf, docx, etc.)

## Status Atual

```bash
# Ver documentos atualmente na pasta
ls -la
```

Se estiver vazio, **adicione seus documentos** antes de gerar capítulos!
